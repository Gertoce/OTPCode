# OTP Service API (Java HW)

Микросервис на Java 21 для реализации двухфакторной аутентификации (2FA). Система поддерживает генерацию одноразовых паролей (OTP), их верификацию, выдачу сессионных токенов и разграничение прав доступа (RBAC).

## 📊 Результаты реализации (Чек-лист)
* **Структура приложения:** Соответствует паттерну DAO-Service-Handler[cite: 1].
* **Система сборки:** Maven (`pom.xml` со всеми зависимостями).
* **API:** Реализовано на базе пакета `com.sun.net.httpserver`.
* **База данных:** PostgreSQL для хранения пользователей, настроек, кодов и токенов.
* **Безопасность:** Хеширование паролей (SHA-256) и UUID-токены.
* **Каналы доставки OTP:**
    * **Email:** Через SMTP Yandex (Jakarta Mail).
    * **Файл:** Логирование сгенерированных кодов в `otp_codes.txt`.

## 🛠 Технический стек
* **Java 21**
* **JDBC + PostgreSQL** — хранение данных.
* **Jakarta Mail** — отправка уведомлений.
* **Logback** — логирование событий.
* **Gson** — работа с JSON.

## 📡 API Эндпоинты
Адрес сервиса: `http://localhost:8080/api/otp`

| Метод | Путь | Описание |
| :--- | :--- | :--- |
| `GET` | `/register` | Регистрация пользователя (`login`, `role`). Пароли хешируются. |
| `GET` | `/generate` | Создание OTP, отправка на Email и запись в файл `otp_codes.txt`. |
| `GET` | `/verify` | Проверка кода. При успехе возвращает **UUID токен**. |
| `GET` | `/admin/users` | Список пользователей. Доступен **только для роли ADMIN** по токену. |

## 📂 Структура проекта
* **`com.otp.dao`**: Объекты доступа к данным (User, Otp, Token, Config).
* **`com.otp.service`**: Бизнес-логика, включая:
    * `AuthService`: Хеширование паролей.
    * `EmailService`: Интеграция с почтовым сервером.
    * `FileService`: Запись кодов в локальное хранилище.
    * `OtpHandler`: Обработка HTTP-запросов и маршрутизация.
* **`Main.java`**: Точка входа и запуск HTTP-сервера.

## ⚙️ Настройка
1.  **Email**: Настройте учетные данные в `src/main/resources/email.properties`.
2.  **DB**: Укажите параметры подключения к PostgreSQL в `DatabaseConfig.java`.
3.  **Логи**: При генерации OTP проверьте файл `otp_codes.txt` в корне проекта — там дублируются все коды.
